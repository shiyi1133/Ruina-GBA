废都物语 GBA · v0.7.1 取名与操作说明版（2026-10-23）

游戏中从菜单“制作信息”查看署名，原作及汉化来源见 CREDITS.txt。

本工程是原生 GBA 的 RM2000 兼容运行时与《废都物语》适配。
原剧情、数值和事件仍读取用户原包的 73 份 LCF 文件，不逐章重写。
这是供评估的开发 DEMO；全剧情、全部结局和实机未验收，也不是完整 EasyRPG 移植。
当前版本可能还有问题。旧 DEMO、原 ZIP 和普通 SAV 均保留。

取名界面
30 个常见姓、100 个名字用字（四页）、26 个大写字母、26 个小写字母、29 个符号、10 个数字。
L/R 循环切换六个分类；方向键选字，移过一页的末尾或开头会自动翻页。
选姓后自动进入名字栏。第一次 A 选字会替换显示的原名。
B 删除最后一个完整字符；SELECT 恢复原名；START 完成。不编辑就按 START 保留原名。
中英文、数字和符号可混合，最多六个字符；空白确认仍保留原名。
符号栏采用常见标点，省略原引擎用于控制指令、图标和选项分隔的三个字符。
本次补齐 11 个字形，原有字形、图像、地图和音频资源保持不变。

操作说明
地图按 B（或 START）打开系统菜单，在“特技”后选择“操作说明”。
共五页：移动与调查、地图视野与标记、菜单与战斗、输入名字、音乐与存档。
左右或 L/R 翻页；B 返回并保持菜单选择，再按 B 返回地图。
说明页面暂停游戏时钟，不消耗物品或触发原剧情。
本轮画面
- 探索底图、图块、地图人物按原尺寸滚动；仅新露出的边缘补图，不随光标移动整屏重绘。
- 背景使用 48 KiB 环形缓存。对话和列表另放一层；普通菜单关闭时直接恢复已有地图。
- 8×8 图块一次完整解码再复制，避免同一图块八行反复解压；不减少原图像素。
- 原始 48×48 头像以独立 RGB555 颜色绘制，多组头像同屏不再挤入一个场景调色板。
- 标题采用缓存的高质量缩放图，其他插图采用 RGB555 与双线性缩放；不再统一压成 15 色。
- 普通列表、物品栏与商店只更新变化行，数量窗口只更新数字；图片菜单比较实际变化区域，再分段提交。
- 物品索引采用紧凑位集，保留原编号顺序与原筛选条件，减少深层菜单的临时内存占用。
- 人物、调查点、当前位置、四边三角箭头和小型 HUD 使用硬件精灵。
- 地图背景保留 16 色界面及至多 240 色原图；少数超出容量的底图仍近似颜色。
- 原 24×32 地图人物保留像素，人物颜色随当前可见对象回收；拥挤场景超出颜色容量时近似。
- 剧情换图直接黑屏后显示新图；普通选项移动不插入黑屏。静态半透明保留。
- 自动寻路经过地面事件时执行原事件，再继续；手动移动会取消远处目标。
- 全屏绘图持续补充音乐队列，最终提交避免跨越可见扫描期。
- 保存压缩、校验、SRAM 读写和地图索引分段补充声音；保存格式与原有数值不变。

本轮声音
全部 99 首 MIDI 保留原曲事件、节拍、控制器和循环；另有 6 首 WAV 配乐和 218 个音效。
音乐欣赏与游戏过程都使用简化音色，不提供原音源分册。
MIDI 在游戏中使用较粗的单声道音色，音乐欣赏使用较细的立体声音色。
6 首 WAV 配乐在两模式共用已转换录音，不因切换合成音色而改变。
标题画面进入“音乐欣赏”，可试听 105 首配乐；不影响普通存档。
原曲使用的音高倍率也保留。合成缓存、音效混合和显示提交分别进行压力抽查。
主机完整乐谱检查、GBA 整曲与循环受控检查、自然游戏流程抽查分别记录，不能混为完整通关。
v0.7 的 105 首配乐 × 两种音色共 210 项整曲检查通过（本次 UI 更新未重跑整曲）；有循环的另覆盖两轮，未见初始填充后的断音或声部溢出。

地图操作
方向键移动当前位置，并取消之前 L/R 选中的远处目标；A 调查脚下或面前的原事件。
短按 L/R 选择远处调查点后，A 才沿实际通路走过去调查；再次手动移动会取消这个目标。
刚进入新地图仍会默认标记第一个可选点；普通 SAV 中零选点表示就地调查，冷读后不会擅自重选。
L+R 只走过去。按住 R+方向键只浏览地图，不移动角色。
黄标可调查，灰标暂不可达；开场最初仅开放入口，调查后再开放其它地点。
四边三角箭头高亮表示视野还能滚动，灰色表示到了视野边界，不代表地形通行。
B 或 START 打开系统菜单，可查看操作说明；A 确认，B 返回。

音乐欣赏操作
上下选择，A 播放或暂停；左右或 L/R 切换并播放；START 切换两种简化音色，B 返回。
切换音色保留播放位置及暂停状态；一次性短曲结束后可按 A 从头重播。
进游戏后恢复省性能的游戏音色。

存档
在原事件允许保存时，B 或 START → 保存游戏，写入 v5 压缩 SRAM 存档。
读取本工程 v2/v3/v4/v5 普通 SAV；不读取 PC 存档或模拟器即时存档。
使用旧存档前先复制一份，再按新 ROM 名称重命名。新旧 ROM 不共用唯一的原档。
Game 状态 39704 字节，压入 32 KiB SRAM；超出容量会拒绝写入，避免覆盖已有进度。
试玩包不预放同名 SAV。工程 evidence/、history/ 的 SAV 是测试材料。

工程重建
Linux/WSL、Python 3、GNU Arm Embedded 工具链：
  python3 tools/build.py --incremental
ARM_TOOLCHAIN_PREFIX 可指定 arm-none-eabi- 前缀。
保留工程包中的 build/ 已转换资源即可重建，不需要原 ZIP、系统字体、Pillow 或 NumPy。
交付流程会在独立目录以 python3 -S 重建，并与实际试玩 ROM 逐字节核对。
重新转换原素材需要 RUINA_SOURCE_ARCHIVE、RUINA_FONT、Pillow、NumPy；
RUINA_ASSET_PYTHON 可指定有这些依赖的 Python，不用修改构建脚本的本机路径。
完整图片转换还可使用系统 liblz4 的高压缩率编码；交付缓存已转换完成，增量构建无需该库。
当前简化音乐重新生成：使用有 NumPy 的 Python 执行 tools/rebuild_simplified_audio.py。
build/native_music/*.events.json 和音源提取缓存是生成输入，不依赖历史工程目录。

模拟器验证另需 mGBA 开发库：设置 MGBA_PREFIX 后执行 python3 tools/build_probe.py。
验证工具只对生产 ROM 发真实按键、读取观察值、截图和复制普通存档；独立测试卡另行标记。
tools/validate_optimization.py 为通用 36 项回归入口；新显示层专测另见工程使用说明。
历史对比需要另存旧版 ROM/ELF，缺失时只测当前版本；本次小版本发布入口为 tools/deliver_ui_update.py；v0.7 原流程为 tools/deliver_balanced.py。
工程不附工具链、原 ZIP、系统字体、旧版 ROM 或全部历史测试卡；可重建不等于 Windows 原生构建已测。
